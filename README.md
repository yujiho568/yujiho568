### 관심 분야

- Java / Spring Boot 기반 백엔드 개발
- Python / FastAPI 기반 데이터·AI API 개발
- MySQL, Redis, SQL 튜닝, 캐시를 활용한 서비스 성능 개선
- RAG, XAI, Doc2Vec/ML 등 AI 기능의 서비스 연동
- Docker Compose, GitHub, CI/CD를 활용한 협업 및 운영 환경 구성
